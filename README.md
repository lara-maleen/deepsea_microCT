# MicroCT vs. Histology: Reproductive Structures in Deep-Sea Sponges and Paragorgia arborea

[last updated 09 Nov 2026]

This repository contains the R scripts and reproducible workflow used to compare micro-computed tomography (microCT) and traditional histology for quantifying reproductive structures in deep-sea invertebrates. The analyses focus on three poecilosclerid sponges (Tedania kagalaskai, Stelodoryx oxeata, Monanchora pulchra) and the octocoral Paragorgia arborea, and include measurement comparisons between the two methods, volumetric estimates of reproductive investment, and siphonozooid-level gamete counts.

The repository includes the R script (Markdown File) plus knitted PDF output, used for data processing, statistical comparison, and visualization.

# Zenodo Archive

The processed datasets (siphonozooid counts and microCT/histology measurements) are archived in Zenodo (https://doi.org/10.5281/zenodo.24086427), which includes specimen-level gamete counts, reproductive siphonozooid summaries, and segmented-object measurements from microCT and histology. Raw microCT volumes and histological slides are not included due to size and are available from the authors on request. The slides are deposited at the Smithsonian Natural History Museum in DC.
